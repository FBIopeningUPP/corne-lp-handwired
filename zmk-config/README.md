# Corne LP — ZMK config

Push this folder to its own GitHub repo. GitHub Actions builds firmware for both halves on every push.

- Pinned to **ZMK v0.3**.
- Uses Pete Johanson's Cirque driver (`config/west.yml`).
- Custom `corne_lp` shield in `boards/shields/corne_lp`.
- Blip's animated status screen is in `src/`.
- See the main README for wiring, flashing and tweaks.
